# CodeAlpha Data Analytics Internship

## Task 2: Exploratory Data Analysis (EDA)

### Project Overview
This project performs Exploratory Data Analysis on the Sample Superstore dataset using Python.

### Objectives
- Understand the dataset.
- Check missing values and duplicate records.
- Clean and prepare the data.
- Analyze sales and profit.
- Identify useful business insights.

### Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

### Dataset Information
- Dataset: Sample Superstore
- Total Records: 9,994
- Total Columns: 21
- Missing Values: 0
- Duplicate Rows: 0
- Data Period: 2014–2017

### Key Findings
1. Technology has the highest sales: 836,154.03.
2. West region has the highest profit: 108,418.45.
3. Technology has the highest category-wise profit: 145,454.95.
4. Furniture has the lowest category-wise profit: 18,451.27.
5. November 2017 has the highest monthly sales: 118,447.825.

### Project Files
- `eda_analysis.py` – Python source code.
- `Sample - Superstore.csv` – Dataset.

### How to Run
1. Install Python.
2. Install required libraries:
   `pip install pandas numpy matplotlib seaborn`
3. Run:
   `python eda_analysis.py`

### Conclusion
The analysis identifies sales and profit patterns across product categories, regions, and months. It provides useful insights into the business performance of the Sample Superstore dataset.
